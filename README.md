# API для проекта Yatube

**Yatube** — это социальная сеть для публикации дневников. Платформа позволяет пользователям создавать свои посты, привязывать их к определенным тематическим группам, комментировать записи других пользователей и подписываться на интересных авторов.

Данный проект представляет собой **REST API** для Yatube, который позволяет взаимодействовать с платформой из любого клиентского приложения (например, с фронтенда на React, мобильного приложения или через Postman).

## Функционал API

* **Аутентификация:** Безопасная авторизация по JWT-токенам (библиотека Djoser).
* **Посты:** Просмотр, публикация, редактирование и удаление постов. Поддержка пагинации.
* **Группы:** Просмотр списка тематических групп и постов в них.
* **Комментарии:** Добавление, изменение и удаление комментариев к постам.
* **Подписки:** Возможность подписываться на других пользователей и просматривать свои подписки. Поиск авторов.

## 🛠 Технологии

* Python 3.9+
* Django 3.2+
* Django REST Framework (DRF)
* Djoser & SimpleJWT
* SQLite3

## Как запустить проект (на macOS / Linux)

1. **Клонируй репозиторий и перейди в папку проекта:**
```bash
git clone <ссылка_на_твой_репозиторий>
cd api-final-yatube-ad

```


2. **Создай и активируй виртуальное окружение:**
```bash
python3 -m venv venv
source venv/bin/activate

```


3. **Установи зависимости:**
```bash
pip install -r requirements.txt

```


4. **Выполни миграции базы данных:**
```bash
cd yatube_api
python3 manage.py migrate

```


5. **Запусти локальный сервер разработки:**
```bash
python3 manage.py runserver

```


Сервер будет доступен по адресу: `http://127.0.0.1:8000/`

## Примеры запросов (Документация)

Все эндпоинты начинаются с префикса `/api/v1/`.

### 1. Получение JWT-токена

**POST** `/api/v1/auth/jwt/create/`

```json
{
  "username": "your_username",
  "password": "your_password"
}

```

*В ответ вернется `access` и `refresh` токены. `access` токен нужно передавать в заголовке `Authorization: Bearer <токен>` для всех безопасных запросов.*

### 2. Получение списка постов

**GET** `/api/v1/posts/`
*Возвращает список постов с поддержкой пагинации (limit, offset).*

### 3. Создание нового поста (Требуется токен)

**POST** `/api/v1/posts/`

```json
{
  "text": "Текст моего нового поста",
  "group": 1 
}

```

### 4. Подписка на пользователя (Требуется токен)

**POST** `/api/v1/follow/`

```json
{
  "following": "vasya_pupkin"
}

```
